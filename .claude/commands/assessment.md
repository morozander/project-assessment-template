# assessment

Start a assessment session for a project.

## Instructions

Read and follow the assessment skill at `.claude/skills/assessment/SKILL.md` exactly as presented.

The skill will guide you through:

1. Understanding the steps that nedds to be done
2. Writing a output to the `./output/<project>`
3. After the assessment output is written, ask the user whether they want to run `.claude/commands/update-assessment-dashboard.md`. If they agree, read and follow that command. If they decline, stop.
